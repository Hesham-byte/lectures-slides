## 🌟 Interactive Slide Portal

You can navigate and preview all lecture slides using the portal:

👉 **[Open Lecture Portal (`index.html`)](index.html)** *(Double-click to open in any web browser)*

### Portal Features
- 🚀 **One-Click Presentation Launch**: Opens the Marp-powered full slide deck in presentation view.
- 👁️ **In-Page Slide Preview**: Inspect slides directly in an embedded modal without navigating away.
- 🔍 **Live Search & Category Filtering**: Quickly filter lectures by topic, lesson number, or key concepts (`/` hotkey).
- 🌓 **Light & Dark Mode**: Seamless theme switching with automatic system preference detection.
- 📱 **Fully Responsive**: Optimized for desktops, tablets, and mobile devices.

## 🎮 Presentation Controls & Shortcuts

When viewing any slide deck, use the following keyboard controls:

| Key | Action |
| :--- | :--- |
| <kbd>→</kbd> / <kbd>Space</kbd> / <kbd>PageDown</kbd> | Advance to next slide |
| <kbd>←</kbd> / <kbd>PageUp</kbd> | Return to previous slide |
| <kbd>F</kbd> | Toggle Fullscreen mode |
| <kbd>P</kbd> | Toggle Presenter View (notes + timer + next slide) |
| <kbd>Esc</kbd> | Exit fullscreen or close preview modal |

## 🛠️ How to Open Locally

1. Clone or download this repository.
2. Double-click [`index.html`](index.html) to open the interactive slide portal in your browser.
3. No build tools, Node.js, or web servers required—it works 100% offline!

*(Optional)* If you prefer serving it via a local HTTP server:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
